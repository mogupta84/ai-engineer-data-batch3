# Day 1: models and prompts in Microsoft Foundry

Start with the handbook, **[Day1_models_and_prompts.pdf](Day1_models_and_prompts.pdf)**. Parts P1 to P5 run in the
Foundry portal; the code part runs in VS Code after the one-time setup in the handbook.

```
Day1_models_and_prompts.pdf  the handbook, with the VS Code setup for Days 1 to 4
paste_texts.txt              every text you paste into the playground, under its part (P2, P3a, ...)
tickets.json                 the 10 support tickets of P4, with their right labels
l1_tokens.py                 tokens and cost per sentence; no Azure call
l1_experiments.py            P2 to P4 repeated and counted, plus embeddings; signed in as you
```
